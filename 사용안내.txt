에이스 정산 계산기 — 공개 웹 버전

PC와 휴대폰에서 같은 사이트를 열고 같은 ChatGPT 계정으로 로그인하세요.
카카오톡 원문 붙여넣기 → 계산하기 → 확인 필요 항목 수정 → 결과 복사.
기록 저장을 누른 정산만 온라인 데이터베이스에 저장됩니다.
단가와 기록은 계정별로 분리되며, PC가 꺼져 있어도 접속할 수 있습니다.

모든 가게의 0.5개는 15,000원입니다. 서로 다른 작업의 반개는 합치지 않습니다.
역삼제우스(역제): 선수 지급 단가 40,000원. 가게 청구액 55,000원과 다릅니다.
모르는 단가는 확인 필요로 표시하고 소계만 계산합니다.
단가 변경은 과거 저장 기록에 적용하지 않습니다.
저장은 지급 완료를 뜻하지 않으며 자동 송금 기능은 없습니다.

로컬 PC 버전의 데이터베이스와 비밀번호는 이 사이트로 옮기지 않았습니다.
현재 계정에는 확정 초기 단가만 기본 제공하며 기록은 처음부터 저장합니다.

개발 검증: node --test tests/app.test.mjs
318개 원문·계산 비교 + 개수 검증 + 직접 수정 + 계정별 DB 격리·재접속 + API 접근·재계산 검증 = 322개 통과. 추가 조회 권한 검증 1개 포함 총 323개 통과.
TypeScript 검사 통과. 배포용 빌드는 Windows 파일 경로 접근 오류로 로컬 완료하지 못했습니다.
서버 빌드를 위한 소스 전송은 자동 승인 검토에서 차단되었습니다. 공개 배포와 실제 휴대폰 접속은 아직 검증되지 않았습니다.

개발 환경 실행 (Node.js 22.13 이상 및 npm 필요):
1. npm ci
2. npm run dev
3. 표시된 개발 주소에서 확인
온라인 저장 기능은 Sites의 DB 연결과 저장된 drizzle 마이그레이션 적용이 필요합니다.
이 압축 파일 자체를 열거나 GitHub Pages에 올리는 것만으로는 온라인 공용 저장 기능이 실행되지 않습니다.

조회 전용 공유
1. 배포 후 은철이가 자기 ChatGPT 계정으로 로그인합니다.
2. 어디서나 접속 화면의 내 계정 코드를 전달받습니다.
3. 소유자가 같은 화면에서 이름과 상대방 계정 코드를 입력해 조회 권한을 추가합니다.
4. 표시된 공유 주소를 전달합니다. 은철이는 로그인한 뒤 같은 단가와 저장 기록을 볼 수 있습니다.
5. 계산·저장·단가/별칭 변경·재공유는 서버에서 차단됩니다. 소유자는 권한 해제 버튼으로 이후 조회를 막을 수 있습니다.
실제 은철 계정은 아직 연결하지 않았으며 배포 차단도 해결되지 않았습니다.
