# 에이스 정산 계산기

카카오톡 작업 내역으로 선수 지급액을 계산하는 반응형 웹앱입니다.

## 모바일 계산기
`docs/`의 계산기는 GitHub Pages에서 main 브랜치의 `/docs` 폴더를 게시합니다. 기본 해석과 금액 계산은 브라우저에서 실행하고, AI 해석은 별도 Sites 서버를 호출합니다.
공개 앱: https://aiultramin-prog.github.io/ace-settlement-calculator/

단가와 기록은 각 기기의 브라우저에만 저장되며, 다른 사람이나 기기와 자동 공유되지 않습니다. '결과 복사'로 카톡에 결과를 보내세요. 원문과 기록은 GitHub에 전송하지 않습니다. 기존 `ace-settlement-github-v1` 저장 자료와 과거 기록을 유지합니다.

### 지급 계산 기준
- 일반 건: 정수 개수 × 가게별 선수 몫 + 반개 15,000원.
- 직수: 선수 몫 − 선수가 이미 직접 받은 금액. 음수 금액은 징대로 차감합니다.
- 직수 금액이 생략되면 등록된 가게 금액으로 계산합니다. 반개는 모든 가게에서 받는 돈 30,000원, 선수 몫 15,000원입니다.
- 최종 합계가 양수면 **선수에게 줄 돈**, 음수면 **선수에게 받을 돈**, 0이면 **주고받을 돈 없음**으로 표시합니다.
- 가게 금액은 확인된 킹스맨 60,000원, 쿨노래방 50,000원, 역삼제우스 55,000원만 기본 등록합니다. 다른 가게는 실제 금액을 등록하며 임의로 추측하지 않습니다.
- 가게별 선수 몫과 받는 금액을 따로 수정할 수 있습니다. 선수·날짜·방 번호는 계산의 필수 입력이 아닙니다.

### 채팅 해석과 모바일 화면
`한개반`, `한 개 반`, `반개`, `두개`, `도파민505` 같은 표기와 한 줄의 여러 가게를 읽습니다. 더하기 합계는 별도의 작업으로 만들지 않습니다. 불명확한 건만 확인하고, 작업 내역을 눌러 수정합니다.

### AI 해석
전용 연결 주소를 각 휴대폰에서 한 번 열면 `AI로 읽고 계산`을 사용할 수 있습니다. 연결 주소는 개인용이며 Git에 포함하지 않습니다. OpenAI API 키는 서버에만 저장합니다. 기본 계산 버튼은 AI 연결 없이도 사용할 수 있습니다.

AI(GPT-5.4 mini)는 가게·개수·직수·실제 수령액을 구조화합니다. 최종 금액과 단가는 AI가 결정하지 않고 `engine.mjs`에서 계산합니다. AI가 읽은 각 작업은 실제 원문 인용과 함께 표시하며, 불확실한 항목은 직접 수정할 수 있습니다. 같은 원문을 다시 계산하면 현재 페이지의 해석을 재사용하고, 개수·단가·직수 금액 수정은 API를 호출하지 않습니다. 실패 시 기본 해석으로 몰래 바꾸지 않으며 오류와 기본 계산 선택을 보여 줍니다.

AI 계산 시 원문과 등록 가게 이름·별칭이 서버를 거쳐 OpenAI로 전송됩니다. Responses API `store:false`를 사용하며 앱 서버는 채팅 원문을 DB에 기록하지 않습니다. 저장 기록과 단가는 브라우저에 보관합니다. AI 서버는 전용 Bearer 연결 코드, 허용 Origin, 입력 크기 제한과 전체 기기 합산 분당 6회·하루 200회 제한을 사용합니다. 하루 제한은 UTC 기준으로 초기화됩니다. API 요금은 ChatGPT 구독과 별도입니다.

AI 서버 소스는 기존 Sites 프로젝트의 `lib/ai-extract.mjs`, `lib/ai-api.mjs`, `app/api/ai/parse/route.ts`에 보관합니다. 런타임 비밀 값은 `OPENAI_API_KEY`, `ACE_CLIENT_TOKEN`이며 공개 소스와 브라우저 번들에는 없습니다. 연결 코드를 바꾸면 기존 기기는 새 주소로 다시 연결해야 합니다.

검증: `node --test tests/*.test.mjs` (기존 사례, 직수·반개·자유 표기, 저장·재접속·기록 불변·AI 전달값 검증). AI 서버에는 별도의 인증·CORS·요청 제한·오류 처리 테스트가 있습니다. GitHub Pages는 `docs/`의 정적 파일을 직접 게시하므로 npm 설치나 빌드가 필요하지 않습니다.

아래는 이전 서버 연결 버전의 설명입니다. GitHub 전용 버전에는 로그인·공유 DB·조회 권한 기능이 없습니다.

## 기능
- 명시적 규칙과 별칭으로 원문 해석. 유료 AI API 불필요
- 모든 가게의 반개는 15,000원. 서로 다른 작업의 반개는 따로 계산
- 미등록 단가·불명확한 작업은 확인 필요로 표시
- 작업 수정, 이번 건 단가, 기본 단가 저장, 결과 복사
- 온라인 DB에 계정별 기록 저장. 과거 기록 금액 유지
- 지정한 계정에 조회만 허용. 서버에서 수정·저장·재공유 차단
- 역삼제우스(역제) 선수 지급 단가 40,000원. 가게 청구액 55,000원과 구분

GitHub Pages의 모바일 계산기와 아래 이전 서버 화면은 저장소가 별개입니다. GitHub Pages만으로 서버·DB·로그인을 실행할 수 없습니다.

## 개발 및 검증
Node.js 22.13 이상과 npm이 필요합니다.

```sh
npm ci
node --test tests/app.test.mjs
npm run dev
```

기술 구성: Vinext / React / Cloudflare D1 / Drizzle.
현재 로그인은 Sites의 ChatGPT 인증에 연결되어 있습니다. 다른 호스팅에 직접 배포하려면 신뢰할 수 있는 인증 연결을 구현해야 합니다. 클라이언트가 보낸 인증 헤더를 그대로 신뢰하는 구성으로 공개하지 마세요.
DB 테이블은 `drizzle/`의 마이그레이션으로 생성합니다. 초기 단가는 코드에서 제공하며 실제 정산 데이터는 포함하지 않습니다.

## 조회 전용 공유
배포 후 상대방이 로그인하여 계정 코드를 알려주면, 소유자가 '어디서나 접속' 화면에서 조회 권한을 추가하고 공유 주소를 전달합니다. 상대방은 같은 단가·저장 기록을 볼 수 있고 계산·저장·수정은 할 수 없습니다. 소유자가 권한을 해제할 수 있습니다.

실제 원문, 계좌번호, DB 파일, 비밀번호, 인증 토큰은 Git에 올리지 않습니다. 테스트 인물은 가상입니다.
