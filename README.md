# 에이스 정산 계산기

카카오톡 작업 내역으로 선수 지급액을 계산하는 반응형 웹앱입니다.

## GitHub만 사용하는 버전
`docs/`에 로그인·별도 서버 없이 실행되는 계산기가 있습니다. GitHub Pages에서 main 브랜치의 `/docs` 폴더를 게시하면 됩니다.
단가와 기록은 각 기기의 브라우저에만 저장되며, 다른 사람이나 기기와 자동 공유되지 않습니다. 은철이에게는 '결과 복사'로 카톡에 결과를 보내세요. 원문과 기록은 GitHub에 전송하지 않습니다.
검증: `node --test tests/pages.test.mjs` (318개 해석·계산 비교, 저장·재접속·기록 불변·저장 실패 처리). 브라우저에서 예시 414,000원 계산 확인.
현재 저장소가 비공개이고 계정의 Pages 화면에 공개 전환 또는 업그레이드가 필요하다고 표시되어, GitHub Pages 게시는 아직 대기 중입니다.

아래는 이전 서버 연결 버전의 설명입니다. GitHub 전용 버전에는 로그인·공유 DB·조회 권한 기능이 없습니다.

## 기능
- 명시적 규칙과 별칭으로 원문 해석. 유료 AI API 불필요
- 모든 가게의 반개는 15,000원. 서로 다른 작업의 반개는 따로 계산
- 미등록 단가·불명확한 작업은 확인 필요로 표시
- 작업 수정, 이번 건 단가, 기본 단가 저장, 결과 복사
- 온라인 DB에 계정별 기록 저장. 과거 기록 금액 유지
- 지정한 계정에 조회만 허용. 서버에서 수정·저장·재공유 차단
- 역삼제우스(역제) 선수 지급 단가 40,000원. 가게 청구액 55,000원과 구분

## 현재 상태
소스 구현 및 로컬 자동 테스트 323개 통과. 공개 사이트 배포는 아직 완료되지 않았습니다.
이 저장소 주소는 앱 접속 주소가 아닙니다. GitHub Pages만으로 서버·DB·로그인을 실행할 수 없습니다.

## 개발 및 검증
Node.js 22.13 이상과 npm이 필요합니다.

```sh
npm ci
node --test tests/app.test.mjs
npm run dev
```

기술 구성: Vinext / React / Cloudflare D1 / Drizzle.
현재 로그인은 Sites의 ChatGPT 인증에 연결되어 있습니다. 다른 호스팅에 직접 배포하려면 신뢰할 수 있는 인증 연결을 구현해야 합니다. 클라이언트가 보낸 인증 헤더를 그대로 신뢰하는 구성으로 공개하지 마세요.
DB 테이블은 `drizzle/`의 마이그레이션으로 생성합니다. 초기 단가는 코드에서 제공하며 실제 정산 데이터는 포함하지 않습니다.

## 조회 전용 공유
배포 후 상대방이 로그인하여 계정 코드를 알려주면, 소유자가 '어디서나 접속' 화면에서 조회 권한을 추가하고 공유 주소를 전달합니다. 상대방은 같은 단가·저장 기록을 볼 수 있고 계산·저장·수정은 할 수 없습니다. 소유자가 권한을 해제할 수 있습니다.

실제 원문, 계좌번호, DB 파일, 비밀번호, 인증 토큰은 Git에 올리지 않습니다. 테스트 인물은 가상입니다.
